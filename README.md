## 💚 WHAT IS GHOSTSTORM?

**GHOSTSTORM** is a colorful, terminal-driven research toolkit for exploring **public geographic, domain, network, earthquake, and web-archive data**. Its **HEXCODEX** guest page turns the tool into a beginner-friendly experience with a copyable installer and 20 guided command recipes.

It is built for curious researchers who want colorful terminal output, source-oriented discovery, and a simple start command instead of hunting down Python filenames.

> **No paid API key is required for the documented guest examples.** Public providers may change, rate-limit, or become unavailable.

## 💜 GUEST START // ONE WORD

Open the [HEXCODEX guest page](https://hellfire13666.github.io/GHOSTSTORM-LAB/), read the **FULL GUEST ONE-PASTE INSTALLER**, and use its **COPY** button. Review the installer before running it on your own Linux machine.

Once installed and the launcher is available in your terminal's `PATH`:

```bash
ghoststorm
```

Try the built-in preview or a public city search:

```bash
ghoststorm --demo
ghoststorm --city "Tokyo, Japan"
ghoststorm --help
```

**No repeat Python filename, no export on every launch, no automatic browser opening.**

## 🌈 HEXCODEX // 20 RECIPES

The guest page includes **20 labeled recipes** with individual **COPY** buttons. Explore cities, coordinate lookups, example domains, archive history, earthquakes, nearby events, and interactive exports.

The recipes also demonstrate how to keep a simple local text record:

```bash
ghoststorm --city "Tokyo, Japan" | tee city-results.txt
```

Commands run **locally in your terminal**, not on GitHub Pages. Recipes that need live results depend on public external services. The optional proxy-file example uses a file you supply yourself.

## 🌈 GHOSTSTORM // VIEW SAVED RESULTS

Huge output? The report saved by the **Mega-Storm** recipe can be opened with the correct rainbow formatting, without scrolling through the original terminal session:

```bash
LESSCHARSET=utf-8 less -R "$HOME/Downloads/GHOSTSTORM-MEGA-STORM.txt"
```

The file must already exist in your own Downloads folder. In the viewer, type `/Tokyo` and press Enter to find matches, `n` for the next match, and `q` to exit. This is **read-only**; it does not change your saved evidence or contact any provider. The [HEXCODEX guest page](https://hellfire13666.github.io/GHOSTSTORM-LAB/#saved-results-viewer) includes a **COPY VIEW RECIPE** button.
